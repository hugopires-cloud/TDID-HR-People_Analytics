# Data

The dataset used in this project is synthetic and was created specifically for portfolio and demonstration purposes.

It contains fictional HR information covering:

- employees;
- departments;
- roles;
- contract types;
- locations;
- remuneration;
- attendance;
- absences;
- performance;
- training;
- employee exits;
- calendar dates.

## Important

No real employee, company or confidential information is included.

The Excel workbook is provided to make the analytical workflow reproducible and transparent.
